🌐 CodePen Overview
CodePen is an online playground for front-end developers to write, test, and showcase their code in real-time. It supports HTML, CSS, and JavaScript and is widely used by beginners and professionals alike.

🧩 Key Sections & Their Purpose
| Section              | Purpose                                                                                                                                |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **HTML Panel**       | Used to structure the content. You can build the layout of your web page using standard HTML elements.                                 |
| **CSS Panel**        | Controls the appearance and design of your page. Style your layout, fonts, colors, spacing, and more.                                  |
| **JavaScript Panel** | Adds interactivity and dynamic behavior to your page. You can write JS code to handle user actions, manipulate content, or fetch data. |
| **Preview Area**     | Displays the live result of your code. It automatically updates as you type, letting you see changes instantly.                        |

🌟 Why Use CodePen?
🔄 Instant Feedback — See the result of your code as you type.
👥 Community Sharing — Share your pens with others or explore thousands of creations.
🧪 Safe Testing — Try new techniques or features without affecting your real projects.
📎 Embeddable Demos — Easily include live previews in blogs, portfolios, or documentation.
